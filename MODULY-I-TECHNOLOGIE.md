# Indeks modułów i technologii SSI

Indeks publiczny nazw i obszarów prac. Nie jest specyfikacją implementacji ani potwierdzeniem, że każdy element został wdrożony.

| Nazwa | Obszar | Powiązane prace / status |
|---|---|---|
| SSI Collective | współpraca i dokumentacja kolektywu | publiczna kronika i zasady |
| SSI Communications | komunikacja i ciągłość dokumentacji | źródło wewnętrzne |
| Universal Lab | środowisko eksperymentów i misji | rozwój |
| Dyrektor | koordynacja misji i delegowanie | rozwój |
| SCC | komunikacja i kontrola współpracy komponentów | rozwój |
| SSI CODEX | narzędzia i środowisko wykonawcze | rozwój |
| MultiQuant | przetwarzanie i eksperymenty z modelami | badania i testy |
| FSE-01 | projekt eksperymentalny MultiQuant | prace rozwojowe |
| SSI-MEM / B1 | pamięć i reprezentacja kontekstu | badania |
| SSI CORTEX | koncepcja warstwy pamięci/kontekstu | propozycja |
| CONTEXT_COVERAGE_GATE | kontrola pokrycia istotnego kontekstu | propozycja |
| SSI Continuity Node NOUT01 | ciągłość pracy i wznowienie ról | testy i integracja |
| RoleExecution | cykl wykonania roli | lokalne testy; odbiór natywny odrębny |
| pressure_guard.py | kontrola presji zasobów | PR i testy lokalne |
| iBet | projekt wykorzystujący role/Iskry | rozwój |

## Zasada interpretacji

Statusy propozycja, badania, testy lokalne, testy hostowe, integracja i wdrożenie są odrębne. Nazwa w indeksie nie oznacza automatycznie gotowości produkcyjnej.
